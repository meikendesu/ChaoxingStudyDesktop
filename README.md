# 学习通助手 Windows 客户端

本项目为 Windows 原生学习辅助客户端。当前版本 **0.3.0 / 精简发布版**，技术栈为 **C# / .NET 10 / WPF / WebView2**。

## 多账号配置

顶部为浏览器风格标签栏：点击标签切换配置，「＋ 新建」「管理」「删除」分别用于创建、重命名/切换/删除与删除当前配置。

**每个账户配置与一个独立 WebView2 实例一一映射**，映射以不可变的配置 id 为键，由 `AccountWebViewPool` 管理：

| 项 | 实现 |
| --- | --- |
| 会话隔离 | 实例池只创建一个 `CoreWebView2Environment`（同一 userDataFolder），每个账户使用独立命名 profile（`cx-<id>`）；默认账户沿用原有默认 profile，已有登录资料不迁移。命名 profile 不可用时降级为独立 userDataFolder，隔离性不变 |
| 后台启动 | 新建账户时在后台隐藏创建实例、注入 `study-agent.js`、加载主页 `https://i.chaoxing.com`；隐藏使用 `Visibility.Hidden`（保留布局尺寸，页面与 DOM 状态继续保留，但不渲染、不接收输入） |
| 切换 | **隐藏当前实例 → 显示目标已存在实例**。目标实例复用，不导航、不重载、不重新初始化、不搬运 Cookie；已加载页面、播放位置、脚本注入与 DOM 全部保留 |
| 状态隔离 | 自动答题缓存、已核验题目、完成追踪与进度计数按账户保存/恢复，切换时互不影响；主窗口的 `browser` / `study` 引用随激活实例切换 |
| 实例同步 | 新增 → 后台预热；移除 → 先切离、保存 Cookie、释放控件，再删除资料目录；重命名 / 设置保存 → 校验清单与实例一致性（id 不变，不重建实例） |
| 资源上限 | 同时常驻实例不超过 `AccountViewPolicy.MaxInstances`（默认 6）。超出时按 LRU 释放最久未激活且非当前的后台实例，释放前保存 Cookie 快照；窗口关闭统一保存并释放全部实例 |
| 加载失败 | 导航失败只标记该实例为 `Failed` 并写日志，不阻断切换；用户显式点「刷新」时重新加载该账户主页。切换流程绝不自动导航 |
| 切换异常 | 回滚显隐、数据目录、配置清单与学习状态，记录 ERROR 日志并沿用原提示框；不改变当前可见页面 |

实例池的输入输出边界与生命周期约束：

| 项 | 约束 |
| --- | --- |
| 输入 | `AccountSwitchRequest(FromId, ToId, ToRoot)`，仅配置标识与目录；不含页面 URL、UI 控件、Cookie 明文、密钥或 DOM 状态 |
| 输出 | `AccountSwitchResult(Applied, Reused, ViewId, InstanceCount, Warning)`，不含 Cookie 内容、题干、答案或 WebView 控件 |
| 生命周期 | 池随主窗口创建；启动阶段创建一次共享 environment 与主实例（复用 XAML 中的 `CourseBrowser`）；后台实例按需创建并常驻；切换不新建、不重建；窗口关闭统一保存 Cookie 并释放全部实例 |
| 禁止行为 | 切换期间不 `Navigate`、不 `Reload`、不 `Stop`、不清站点数据、不重新注入脚本、不刷新设置控件、不回到主页 |

每个配置拥有独立目录与独立 `settings.json`、`task.json`、`session-cookies.bin`、`profile-cookies.bin`、`profile.json`，Cookie 互不串用。默认配置的目录就是数据根目录，原有资料与登录态保持不变；新建配置位于 `configurations/<id>/`。配置清单为数据根目录下的 `profiles.json`。AI 模型配置 `.env` 为应用级共享；如需为某个配置单独设置，在设置页保存一次即可生成该配置目录下的独立 `.env`（未生成时回退到全局配置，保证新建配置立即沿用全部功能）。默认配置不可删除，其余配置删除时自动切回默认配置。

其余功能（视频/音频阈值推进、文档浏览、题目识别与 AI 答题、字体/OCR、提交确认、Cookie 加密恢复等）对所有配置完全一致。

## 按课程执行自动流程

概览页「按课程执行自动流程」以**当前已打开的、带各个任务点的课程页面**为唯一起点编排整门课程；页面已由用户在程序窗口内打开，流程不会获取、进入或跳转页面。与原有的「开始自动播放」并存，不改动后者的行为。

网页代理明确区分四类互斥页面，由结构判定而非 URL 猜测：

| 页面类型 | 判定依据 | 说明 |
| --- | --- | --- |
| `course` 课程页面 | 存在章节任务点目录树（`#coursetree` / `.posCatalog` 等）且至少一个任务点 | 唯一可用于检查「该课程全部任务点」的页面 |
| `study` 学习页面 | 有任务点标签 / 音视频 / 题目 / 文档，但没有章节目录树 | 章节具体内容，通常是子框架；不会被当作课程总览 |
| `catalog` 课程列表页 | 已登录界面中的课程入口卡片或链接 | 仅用于识别「当前不在课程页面」；流程**不会**点击进入 |
| `other` | 以上都不是 | 等待用户把当前窗口切到带各个任务点的课程页面 |

流程：以当前已打开的课程页面为起点，先读取该课程**全部任务点**及完成标记（不导航、不重载、不重新进入）→ 若全部完成，直接弹窗提示该课程已完成自动流程，不启动播放；若存在未完成任务点，点击第一个未完成任务点并复用原有自动播放/答题流程 → 全部任务点连续两次确认完成后弹窗提示自动流程完成并停止流程。两次确认用于避免目录重绘时的瞬时标记误报。弹窗标题与内容均包含课程名及 `courseid`/`clazzid` 标识，确保明确对应课程；课程名缺失时退回课程标识或页面地址。当前页面若是学习页面或课程列表，只给出提示，不做任何跳转。切换账户或点击「停止自动流程与播放」会同时结束课程级编排。

原「开始自动播放」、手动播放、答题、提交、多账户切换与 Cookie 隔离逻辑均未改变；课程流程停用时不读取页面。

**自动播放与配置切换**：自动播放是每个配置独立的开关。切换配置时若切出前正在自动播放，播放开关会接续到目标账户（只恢复开关与前台焦点，不导航、不重载、不重建实例）；若切出前未启动，目标账户保持未启动，状态栏明确提示「点『开始自动播放』启动」。答案缓存、完成追踪、Cookie 与页面状态仍按账户严格隔离。

### OCR 识别处理

字体解密与 OCR 链路包含以下处理逻辑：

| 项 | 说明 |
| --- | --- |
| 题干清洗 | `_cleanQuestionText` 等价逻辑：HTML 实体（含双重编码）解码、去题号 / 题型标签 / 分值角标；清洗后为空时保留原文，避免纯题型标签题干被「题干为空不提交」门控误阻 |
| 选项 `aria-label` | `_extractOptionPairs.pickText` 的路径：优先读取选项文本节点（`.after` 等）自身的 `aria-label`，再回退到选项行容器与 input |
| 私用区混淆字符 OCR 回退 | DOM 提取失败时按实际字体渲染整题 OCR；允许非 `.font-cxsecret` 容器内的私用区字符成为 OCR 候选，并纳入 `PrepareOcrAsync` 处理范围 |

字形路径 MD5 后 8 位、`Table.json` 映射、字体跨文档查找、`font-cxsecret` 只读映射（不改写 DOM）、本地 Tesseract 5 与置信度门槛、字体域名白名单等均保持不变。离线回归新增题干清洗、选项 `aria-label`、私用区 OCR 回退与页面类型互斥断言。

## 当前能做什么

- 音频课程复用视频的自动流程：识别 `audio` 及“音频 / Audio”任务标签，显式开始时选择首条媒体，随后顺序播放；共用倍速、阈值、停止及章节完成标记判断。音频与视频分别统计，课时进度合并展示，隐藏任务媒体不参与。新增离线 WebView2 回归，真实音频课程的平台学习记录仍需复测。

真实音频补充适配：Video.js 隐藏的 `audio.vjs-tech` 按可见的音频播放器容器判断，通过已有播放器启动；后台试听、备用 audio 及隐藏任务仍排除。详见 [音频实页修复记录](docs/2026-11-03-音频课程流程.md)。

- 在原生桌面窗口内打开学习通、超星网站，使用网页正常登录。
- 固定浏览器资料目录，跨进程保留持久 Cookie 和网站存储；超星/学习通的会话 Cookie 退出时使用 Windows DPAPI 加密保存，启动时恢复，最长保留 7 天。平台自身会话过期或撤销仍需重新登录。
- 设置页提供 15 个 Provider 配置标识及接口地址、模型名称输入；每次进入重新读取当前 .env，保存更新同一文件。
- 模型 API Key 按用户要求保存到本地 .env，不回显、不注入网页、不进入普通设置 JSON 或发布包；.env 是明文文件，请勿分享。旧 DPAPI 密钥库保留但不参与 AI 调用。
- 注册跨域及嵌套 iframe，读取视频、题目和课程章节标记；删除旧版顶层消息桥接，统一由原生端直接读取各框架，网页消息入口关闭。
- 点击“开始自动播放”时优先选择第一个视频标签，即使网页当前选中了后面的视频；随后按页面顺序播放后续视频，轮询不会重复点回第一条。视频播放到配置阈值（默认 91%）后，先检查右侧目录对应章节的完成标记：已完成且开启自动切章时，优先进入下一章；否则继续原来的同章视频及任务点流程。倍速 1x–3x 可调。
- 右侧依次展示课程类型、章节完成比例和当前课时的视频播放比例，每 2 秒读取一次；某课程全部章节标记完成后自动重新加载核对，每次运行对同一课程只触发一次。
- 无独立 AI 智能答题面板。进入题目页面后自动读取根目录 `.env`，调用模型并填写、读回核验，支持单选、多选、判断和多空题。当前文档全部识别题目填写并核验通过后，自动点击提交及提交确认；漏题、不支持题型、题目变化或网页提示未答题时不确认提交。同一组答案只点击一次提交，服务器是否接收以网页反馈为准。
- 文档任务点（PPT/PDF/课件）自动翻页浏览；支持超星网盘 `/screen/v2/` 内层阅读器及滚动式文档，将实际正文滚动区滚到底部，等待至少 2 秒，内容延迟增长时继续滚动。保留末页判断，章节完成仍以平台标记为准。
- 兼容文档 iframe 先访问 `/mooc-ans/screen/file` 再跳转到网盘阅读器，避免正文已显示而外层持续“等待文档加载”。详见 [文档等待修复](docs/2026-11-03-文档等待修复.md)。
- 每次启动直接打开学习通首页；有历史课程时可点击右侧“恢复上次课程”。
- 展示最近 50 条运行日志，独立删除密钥或清除浏览器资料。

已实现 `font-cxsecret` 字体解析：搜索当前、可访问父页面及嵌套文档的字体定义，支持分组与导入规则；页面字体下载失败时回退到原生下载（不受网页 CORS 限制），缓存字体数据；使用 Typr 字形路径、MD5 后 8 位与 Table.json 映射。为减少处理量，仅计算当前题目中使用的字符，不遍历全部 CJK 范围。原生下载仅允许学习通/超星 HTTPS 域名，每次重定向重新校验，最多 8 MB，可停止取消。保留自定义选项识别；字体映射只用于读取题目，不修改网页文字，真实课程适配正在验收。解析失败或字符映射不完整时仍提示手动处理。

图片文字 OCR 已接入本地 Tesseract 5（独立安装 `chi_sim`、`eng` 语言包）：分别识别题干和选项图片；字体映射失败时，将实际字体渲染成图片再识别。结果绑定原图/原文字，资源变化则失效。平均置信度低于 75%、任一文字置信度低于 35%、空结果或识别失败时仍阻止自动提交。OCR 仅提取文字，不能保证数学公式、图形关系或低清图片的识别正确性，须人工核对。安装和配置见 [OCR 使用说明](docs/OCR使用说明.md)。

2026-10-22 题目处理逐项对照：修复包装容器合并多题、选项索引错位、分组多选识别、已生成答案在页面重绘后重复请求或未恢复的问题；已正确填写的选项和填空不重复触发修改。优先切换整卷浏览；有完整题号栏的同文档分页会逐页填写核验，等待正文更新，全部页通过后才交卷。逐题“保存/保存答案”只在读回通过后执行一次。无完整题号栏且无法整卷显示、跨文档题号跳转等未核验分页会暂停交卷。对照范围与测试证据见 [题目填写与 OCR 对照验收](docs/题目填写与OCR对照验收.md)。

**尚未完成**：代码签名、多 Windows/DPI 实机验证、未知题型及布局的全面适配。自动播放期间启用鼠标离开、窗口失焦和可见性事件保护，停止后解除保护。

## 直接运行

富文本填空：支持真实课程的 UEditor 多空 iframe，包括外层空格可见、编辑器内部折叠的布局。写入前检查实例就绪与可编辑状态，答案按纯文本转义，通过现有编辑器同步到表单；提交前同时核验正文及提交值，缺空、只读或同步失败时仍拒绝提交。

混合课程推进回归：隐藏的同源任务 iframe 不再计入视频/题目；测验激活后不会重新选择前面的视频，也不会再次打开当前测验。章节仍须有平台完成标记，且开启“章节完成后自动进入下一节”才跨章。跨域 iframe 的外层可见性无法由此检查，真实课程仍需复测。

2026-10-22 补充回归：任务点兼容 `.chapter_tab` / `.ans-cc-tab`，点击实际的内层控件；跨框架导航重绘后识别当前视频标签，避免重新加载当前视频阻塞测验。字体源除了固定名称，还按 `.font-cxsecret` 元素的实际计算字体家族匹配。上述情况已离线复现并验证，仍需在报错课程上复测；不存在可读取字体定义时继续停止自动提交。`--dump-page` 诊断模式只读结构，不触发播放、答题或提交。

本机正式入口为 `%LOCALAPPDATA%/Programs/ChaoxingStudyDesktop/current/学习通助手.exe`，也可使用 `artifacts/学习通助手.lnk`。分发暂存位于 `artifacts/portable/current/`，最新完整运行时包为 `artifacts/publish/学习通助手-完整运行时-win-x64.zip`。EXE、窗口与页头使用蓝色书本勾选图标。此入口保留字体解析、自动答题/二次提交、界面与配置优化及视频阈值推进修复。

## 从源码开发

答案格式兼容：可接收一个完整的 JSON 代码块；代码块前后的解释、未闭合块、越界选项和缺空答案仍拒绝。格式或数量不符时，每题最多增加一次带明确校验要求的重试，沿用原总超时和取消机制；模型明确返回空数组时不强制补答案。失败日志显示本轮题号、题型和具体原因，不记录题干、答案或密钥。

## 数据与运行边界

默认数据目录：`%LOCALAPPDATA%/ChaoxingStudyDesktop/`。若该目录不可写，项目内的发布包固定使用 `artifacts/client-data/`，不同版本共用；首次从最近使用的发布包 `data/` 复制现有资料，不删除旧资料。迁移时应先关闭旧客户端。已存在的固定资料不会被旧包覆盖，独立移出项目的发布包则回退到自身 `data/`。实际路径见“设置”。

| 文件或目录 | 内容 |
| --- | --- |
| `settings.json` | 当前选中的 Provider，不含 Key |
| `secrets/<provider>.bin` | 旧版 DPAPI 密钥，保留但不再用于 AI 请求 |
| `.env`（程序目录或项目根目录） | 当前生效的模型配置及明文 API Key，不可公开分享 |
| `BrowserProfile/` | WebView2 Cookie、缓存、网站存储与登录资料 |
| `session-cookies.bin` | DPAPI 加密的超星/学习通会话 Cookie，当前 Windows 用户可恢复，最长 7 天 |

损坏的配置在读取时保留原文件并给出提示；用户显式保存后才覆盖。无法解密的密钥不会自动当作空值覆盖。日志仅存在本次进程内，不输出完整网址、Authorization、题干或密钥。不要将浏览器资料或真实 Key 提交到 Git。

“停止自动流程与播放”会取消 AI 请求、后续填写及章节推进，暂停已发现媒体并停止导航；进度只读刷新仍继续。网页自己的后台网络活动不在该停止指令范围内。

总体进度按已识别目录的完成章节数计算，并非平台任务点加权完成率；未找到目录显示待确认。视频进度仅表示当前课时已加载媒体的播放位置，不是全课程视频完成率，也不证明服务端已记录学习。平台页面布局、分页目录和特殊嵌套内容仍须真实课程核验。
