# 0.3.0 精简发布验收

## 修改范围

本次只移除独立浏览器课程后台及其关联代码，不改动原油猴脚本或技术方案，不增加依赖。当前学习页的章节目录读取属于学习流程，继续用于章节进度、完成判断、自动切章和恢复课程。

删除 13 个后台专用文件：

- `src/Desktop.Core/CourseCatalog.cs`、`CatalogWebServer.cs`：后台课程模型、本机 HTTP 服务。
- `src/Desktop.App/MainWindow.Catalog.cs`、`CatalogCheck.cs`、`Browser/CourseCatalogBrowser.cs`：后台入口、诊断命令和隐藏采集器。
- `src/Desktop.App/SmokeTest.Catalog.cs`、`tests/Desktop.Core.Tests/CourseCatalogTests.cs`：已删除功能的专用测试。
- `src/Desktop.App/Assets/catalog.html`、`catalog-reader.js`、`catalog-fixture.html`、`catalog-fixture-done.html`、`catalog-fixture-todo.html`、`catalog-fixture-empty.html`：后台页面、解析器和离线数据。

修改文件：

- `src/Desktop.App/MainWindow.xaml`、`MainWindow.xaml.cs`：移除后台按钮、地址、隐藏窗口和生命周期处理，页脚更新为 0.3.0。
- `src/Desktop.App/App.xaml.cs`：删除 `--catalog-check` 分支。
- `src/Desktop.App/Desktop.App.csproj`：版本更新为 0.3.0。
- `src/Desktop.App/SmokeTest.cs`：删除后台专用调用，增加后台入口/隐藏窗口/编译类型移除检查、发布资源残留检查、页脚与程序集版本一致性检查。
- `scripts/dev.ps1`、`deploy-local.ps1`：升级时删除旧后台资源。
- `scripts/verify-portable.ps1`：拒绝携带已下线后台页面的发布目录。
- `scripts/deploy-local.ps1`、`scripts/cleanup-deployments.ps1`：统一为带 BOM 的 UTF-8，修复 Windows PowerShell 5.1 按系统编码读取中文导致的解析错误；已使用 Windows PowerShell 5.1 实际部署、预览和清理验证。
- `README.md`、`TASKS.md`、`docs/便携版说明.txt`、本文：同步当前行为和验收说明。
