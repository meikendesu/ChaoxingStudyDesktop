# 自动播放与自动答题调整

日期：2026-10-21。

## 行为

- 点击“开始自动播放”，先点击网页当前的视频标签；未选中视频时点击第一条。之后按页面顺序播放后续视频，不重复点回第一条。
- 当前界面不再提供独立 AI 智能答题面板。检测到题目即读取根目录 `.env` 并自动生成、填写和读回，不要求先开始播放。
- 同一文档中已成功填写的同一道题不重复调用模型。题目改变后重新处理，页面导航后不填写迟到答案；失败后等待 30 秒再试。
- 停止按钮同时取消正在处理的请求和后续填写，关闭自动答题；开始按钮重新启用。提交由用户在网页核对后操作。
