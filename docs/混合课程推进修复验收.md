# 混合课程推进修复验收

用户反馈“视频学习＋答题考核”有两种卡住情况：视频后不进入题目，题目提交后不进入下一章。

本次修改：

- `src/Desktop.App/Assets/study-agent.js`：元素可见性按所属文档计算，并检查同源祖先 iframe 是否隐藏。修复隐藏旧视频仍计入待播放数量、隐藏题目仍进入答题检测的问题。当前测验激活时，将其之前的视频标签视为已经进入，不再回点；任务点推进仅选择当前任务之后的非视频项目，不重新打开当前测验。
- `src/Desktop.App/SmokeTest.cs`：新增混合课程回归，覆盖隐藏 iframe 排除及重新显示、测验激活时不重播、不重复进入当前测验、平台未完成时等待、完成标记出现后只点击一次下一章。
- `README.md`、`TASKS.md`、本记录：同步行为、验证和限制。

旧实现失败证据：

1. “隐藏任务 iframe 仍计入视频/题目，可能阻塞混合课程推进”。
2. 修复可见性后，继续复现“测验已激活仍重新点击之前的视频”。
3. 修复视频选择后，继续复现“当前测验再次被当成下一任务点”。

逐项修复后，源码两阶段 WebView2 回归通过（`910cdf03e4a04f87bdd4550245cf1e6c`），38 项核心测试通过。最终便携包验证结果另存为 `mixed-workflow-seed.json`、`mixed-workflow-verify.json`。保持依赖外部 .NET 10 Desktop Runtime x64 和 WebView2 Runtime 的便携发布，不加入运行时或安装器。

最终发布包 seed/verify 均通过（`8673e8dae35c461e94ecceb0a047de75`），ZIP 20 文件与部署目录 SHA-256 一致。清理 27 个已知构建及验收缓存目标，334.67 MB，0 失败；清理前后 2598 个真实资料/配置文件哈希一致。基线保存在 `artifacts/preserved-user-data/mixed-workflow-baseline.json`。此前被自动审批拒绝删除的旧 ZIP 继续保护并跳过，没有重试。

验证步骤：关闭旧客户端，重新启动 `artifacts/portable/current/学习通助手.exe`，进入课程后点击“开始自动播放”。视频达到阈值/自然结束后应推进后续任务；题目提交后等待网页反馈，平台标记章节完成且“章节完成后自动进入下一节”已开启时才跨章。不要把本地点击提交当成服务器已接收；漏题、字体失败或未完成标记仍应等待。

限制：此次复现来自离线页面，未在用户真实课程执行作答或提交；跨域 iframe 的外层可见性不能通过同源祖先检查判断。若真实页面仍停住，需要实际状态诊断，不能宣称所有课程已通过实机验收。真实 Cookie 与 .env 不进入便携包，清理仅针对已知构建/测试产物。
