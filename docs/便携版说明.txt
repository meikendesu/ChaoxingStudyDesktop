学习通助手 0.3.0 · Windows x64 便携发布

双击 学习通助手.exe。移动或复制时请保留整个文件夹和 Assets。
本包包含 .NET 10 Desktop 自包含运行时和微软 WebView2 固定版 156.0.4314.58 x64，无需另行安装这两项。
请勿只复制 EXE：同目录 DLL、JSON、runtimes、Assets 和 WebView2Runtime 均需保留。
WebView2Runtime 内包含完整浏览器运行时、资源与文件校验清单；程序将其校验、缓存到本机用户目录后运行，首次启动约需十余秒。
请在普通用户目录解压运行。项目工作区可能给 EXE 附加低完整性标签；遇到缓存访问被拒绝时，在项目内运行 scripts/deploy-local.ps1，可部署到 %LOCALAPPDATA%/Programs/ChaoxingStudyDesktop/current。
该脚本首次部署时迁移并校验现有 Cookie 和配置，保留原资料；新 EXE 可直接双击。不会更改 Windows 安全设置。
目标是 Windows 10/11 x64；不支持 Windows 7/8 或 32 位 Windows。
完整解压后双击 学习通助手.exe。不要直接从 ZIP 内运行。

AI 配置：
优先读取 EXE 旁 .env；不存在时，项目内读取项目根目录 .env。
在设置页填写提供商、HTTPS 接口地址、模型和 API Key，点击保存即可创建或更新 .env。每次进入设置会重新读取文件，未保存输入会丢弃。
同提供商留空密钥保留旧值；更换提供商需填写新密钥。该文件是明文，请妥善保管。
发布包不携带真实 Key。不要把自己的 .env 或登录资料公开分享。

登录资料：
旧部署已清理，现有 Cookie 与配置保留在原数据目录，并有独立备份。
优先复用项目 artifacts/client-data 或 Windows 用户数据目录；系统目录不可写且程序独立放置时回退到程序旁 data。
本版本不保证登录资料随文件夹跨电脑迁移。更换 Windows 账号或电脑后可能需要重新登录、重新配置密钥。
旧密钥库和会话的 Windows DPAPI 加密与当前 Windows 用户相关。

运行资源：
Assets 内页面、网页代理、字体解析器、映射表和许可证属于必要资源，不要删除。
测试页面、调试符号、真实密钥和登录资料不随 ZIP 分发。
固定版 WebView2 不会自动升级；后续需重新构建部署包以更新浏览器。
按“开始自动播放”启用视频流程与防暂停；按“停止自动流程与播放”同时停止自动答题和后续提交。

启动直接打开学习通首页。右侧顶部提供后退、刷新、主页与取消静音。
独立浏览器课程后台已移除；当前课程的章节进度、自动切章和恢复上次课程继续保留。
WebView2 默认右键菜单已关闭；每次启动默认全局静音，可随时取消。

图片文字 OCR（额外依赖）：
需独立安装 Tesseract 5 与 chi_sim、eng 语言包，本包不携带引擎。安装入口 https://github.com/UB-Mannheim/tesseract/wiki
默认检测当前用户或 Program Files 下的 Tesseract-OCR，也可在 .env 设置 CX_OCR_PATH=完整的tesseract.exe路径。
详细说明见同目录 OCR使用说明.md；缺失引擎、低置信度或未识别图片不会被当成已完成题目。
OCR 只提取文字，公式、示意图和复杂图文题仍需人工核对。
