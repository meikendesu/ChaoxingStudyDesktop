# 浏览器课程后台

本次在现有 C# / .NET 10 / WPF / WebView2 项目内增加课程目录后台，无新增依赖。学习通为唯一业务数据源，目录只保存在本轮进程内。

## 使用与部署

正常登录新版客户端，在概览点击“在浏览器打开课程后台”，然后在浏览器点击“从学习通刷新”。默认地址为 `http://127.0.0.1:17653/`，端口冲突时以客户端实际地址为准。支持课程及章节名称搜索、已完成/未完成/待确认筛选和章节详情。

服务仅在本机可访问，客户端退出后关闭。清除客户端登录资料会关闭服务并丢弃目录数据。当前正在运行的旧客户端不会被强制关闭，也不会在运行中替换；新版发布后可正常退出旧客户端，再执行 `powershell -ExecutionPolicy Bypass -File .\scripts\deploy-local.ps1 -Launch` 更新正式入口。

## 隔离与状态规则

- 独立隐藏控件共享现有 WebView2 环境及登录 Profile，不使用复习控件，不安装 StudyBrowser 或 study-agent。
- 课程目录页关闭站点脚本；原生解析脚本仍可运行。阻止子 iframe 导航与媒体请求，不进入任务点，不播放、不答题、不提交。
- 根据课程外壳中“章节”的链接及平台隐藏字段生成章节地址，兼容平台跨子域跳转；直接由隐藏 WebView2 读取，避免网页 fetch 的跨域限制。
- 顶层分组标题保留在目录中，但不计入课程完成判定。可确认的非分组章节全部完成时标记课程已完成；有明确待完成任务点时标记未完成，其余保留待确认。
- 本机 HTTP 服务校验 Host、Origin 及每次启动生成的 API 令牌，不提供任意文件或任意 URL 读取接口；页面按纯文本显示平台名称。

## 仍需注意

未知标记不会推断为已完成；特殊学校模板、超大课程分页及网络不稳定仍可能显示待确认。章节完成状态不代表课程成绩、学分或服务端任务点加权完成率。后台和复习控件共享登录状态，退出登录会同时影响两者。真实采集过程中原复习窗口仍保持运行；未对学习行为、题目或成绩做任何操作。
