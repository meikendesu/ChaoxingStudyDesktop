# 文档正文已显示但一直等待加载

## 原因与修改

真实文档外层为 `/ananas/modules/pdf/index.html`，`iframe#panView` 的 src 为 `/mooc-ans/screen/file`，导航后才进入网盘 `/screen/v2/`。旧判断只识别后者，外层和内层均被计作文档；原生轮询先选中没有正文滚动区的外层，持续返回“等待文档加载”。只读诊断确认内层正文高度约 16016、视口高度 546，但始终停在顶部。

补充识别网盘跳转入口，使外层让内层处理正文。只对可见、地址非空的阅读器框架委托；隐藏和空地址占位框架不影响外层自身文档。未改平台完成标记、滚动到底后的稳定等待和切章条件。
