## 本次实现

- **视频完成阈值（默认 91%）**：达到阈值自动进入下一个任务点（同章下一视频、章节测验 tab），而非直接切章；仅平台完成标记才切章。阈值与倍速在概览页可调，持久化并同步到网页代理。
- **倍速**：1x / 1.25x / 1.5x / 2x / 3x，默认 2x，播放时应用并随 2 秒轮询恢复。
- **提交确认**：检测页面“提交/交卷”按钮，“提交答案”按钮始终弹确认后点击；不自动交卷。
- **弹题/章测自动答题**：开关（默认关闭），检测到题目即生成并填写；仅填写不自动提交。
- **文档任务点翻页**：PPT/PDF/课件，`下一页`/缩略图推进 + 页码与末页判定。
- **恢复任务**：记录上次课程，启动时提示恢复（可拒绝）。
- **未签名分发包**：`dev.ps1 package` 输出 zip；版本比较工具 `VersionInfo`。
