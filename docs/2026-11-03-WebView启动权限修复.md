# WebView 启动权限修复

2026-11-03 工作区发布程序启动失败，日志停在准备 WebView2 运行时，异常为 `UnauthorizedAccessException`，调用点为 `BrowserRuntime.GrantRuntimeReadAccess` 的权限写入。

原实现每次启动都重新写缓存目录的读取权限，随后重写相同的 `runtime-manifest.json`，即使运行时缓存已准备完毕。受限进程无法执行这类无必要的写入，因此在创建 WebView2 环境之前失败。

修复后先检查两项原有 AppContainer 读取/执行规则，规则已存在时不再写 ACL；缓存清单内容未变化时不再写文件。缓存内所有文件仍验证 SHA-256，损坏文件仍从包中验证、修复。未降低权限要求，未跳过完整性检查，未清理或替换 BrowserProfile。

- `tests/Desktop.Core.Tests/BrowserRuntimeTests.cs`：使用只读共享锁占用已验证缓存清单，验证重复准备无需写入；原实现稳定失败，修复后通过。
