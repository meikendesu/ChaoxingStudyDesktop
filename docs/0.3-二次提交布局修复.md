# 二次提交弹窗布局修复

日期：2026-10-21。

用户要求点击页面提交后，再点击对话框内的“提交”。现有代理只识别部分通用弹窗，漏掉原脚本已经支持的 `.popDiv`、`.popbox` 等容器，也未识别有 onclick 的 span/div 确认按钮。尚未读取用户当前真实弹窗的 DOM，本次修复针对代码中可复现的布局缺口。

## 修改

- `src/Desktop.App/Assets/study-agent.js`：补充平台自定义弹窗、HTML dialog/aria-modal；确认按钮支持有点击处理的 span/div 和既有自定义按钮类；匹配按钮文字前移除空白。继续只在本次提交后出现的确认框内点击，保留未答题阻止、禁用按钮检查、停止取消和去重。
- `src/Desktop.App/SmokeTest.cs`：新增 `.popDiv` 内 span 按钮“提 交”的回归测试，以及已有弹窗不能误点的断言。
- `README.md`、`TASKS.md`、本记录：说明支持范围、交付位置与重启要求。
