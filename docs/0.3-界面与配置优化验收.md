# WebView2、界面与配置优化验收

## 本次变更

- 在 WebView2 初始化时关闭默认右键菜单，并设置整个浏览器静音。右侧顶部可取消静音及再次静音；导航不重置本次选择，重启默认静音。
- 移除地址栏、打开、重新读取、重复登录按钮及标题右侧版本徽标。后退、刷新、主页、静音集中在右侧顶部；网页区域使用释放的高度。
- 启动直接访问 https://i.chaoxing.com；保留“恢复上次课程”可选入口，不再弹出启动恢复询问。
- 设置页新增接口地址与模型名称，每次进入从 .env 重读。保存写入同一文件；缺失时创建，保留注释及无关变量、清除重复模型配置项。先校验，再写临时文件并替换。
- 同提供商留空保留磁盘密钥，换提供商不复用旧密钥。密钥不回显、不注入网页。旧密钥库保留但不参与 AI 请求；删除当前密钥兼顾旧密钥库。
- EXE 旁 .env 优先；不存在时项目内查找解决方案根目录，项目外使用 EXE 旁路径。设置与 AI 使用相同解析规则，每次请求重新读取。
- 自动答题、填写核验、两阶段提交、防暂停、视频/文档推进及登录资料逻辑保持。

## 交付与手工复核

运行 `artifacts/portable/current/Desktop.App.exe`，或解压 `artifacts/publish/ChaoxingStudyDesktop-portable-ui-env-win-x64.zip`。旧 `artifacts/publish/current` 未同步本次原生界面变化。

1. 退出旧客户端，启动新版，确认直接进入学习通及右侧导航布局。
2. 在视频或嵌套页面点击右键，检查默认菜单不出现；播放时使用取消静音/静音，再刷新或跳转检查选择保持。
3. 进入设置，填写完整提供商、接口、模型与新密钥并保存；切换标签后返回，确认配置重新读取，密钥不回显。留空保存仅同提供商保留已有值。
4. 正常登录课程，复核真实平台的视频、自动答题与二次提交反馈。

测试全部使用隔离目录和假密钥，没有覆盖用户真实 .env，也没有额外调用真实模型。真实课程交互及扬声器听感仍需现场复核。.env 是明文配置文件，不能等同 DPAPI 加密，请勿分享；进入设置会丢弃未保存输入，重新显示磁盘配置。仍需 WebView2 Runtime。
