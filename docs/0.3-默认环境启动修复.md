# 默认环境启动修复

## 原因

2026-10-22 在未覆盖 TEMP/TMP 的环境直接运行原便携包，进程立即退出，退出码 `-2147450721`。标准错误如下：

```text
Failed to create default extraction directory [C:\Users\N5123\AppData\Local\Temp\.net]. No error, error code: 5
Failure processing application bundle.
Failed to determine location for extracting embedded files.
DOTNET_BUNDLE_EXTRACT_BASE_DIR is not set, and a read-write cache directory couldn't be created.
```

错误发生在 .NET 启动器阶段，WPF 和应用启动日志尚未运行。原发布将原生依赖全部打入 EXE，启动必须解包至系统 TEMP/.net。之前测试继承了构建使用的可写临时目录，因此未覆盖用户正常双击的环境。

## 修复与修改文件

- `src/Desktop.App/Desktop.App.csproj`：关闭原生库自解包，保留托管程序集压缩；6 个必要原生 DLL 随程序分发；关闭 WebView2 Loader 的重复目录输出。
- `scripts/verify-portable.ps1`：必须存在指定的 6 个原生 DLL，继续拒绝其他散装 DLL、调试文件和测试资源。
- `scripts/dev.ps1`：打包、隔离验收副本均包含原生 DLL。发布验收子进程恢复用户/机器默认 TEMP/TMP，并去掉 DOTNET_BUNDLE_EXTRACT_BASE_DIR，避免构建环境掩盖启动问题；失败记录启动器标准错误。
- `docs/便携版说明.txt`、`README.md`、`TASKS.md`、本文：更新分发方式、入口及验证说明。

没有修改系统临时目录权限、机器环境变量、学习功能或用户真实 .env 和登录资料。

[微软单文件部署说明](https://learn.microsoft.com/en-us/dotnet/core/deploying/single-file/overview#native-libraries)解释了原生库内嵌后的磁盘解包要求与默认位置。

2. 正式发布结构检查通过：17 文件、67.02 MB，不含真实配置或用户资料。
3. 核心测试 35/35 通过。
4. 发布版在默认 TEMP/TMP 下的两阶段完整 WebView2 验收均通过：`artifacts/smoke/aec6fc26c5fe4baaaf285cdbc1880ccd/seed.json`、`verify.json`。覆盖原有媒体、答题、二次提交、防暂停、配置和跨进程登录资料。
5. 正式 `artifacts/portable/current/Desktop.App.exe` 无参数正常启动，窗口标题“学习通助手”、有效窗口句柄、Responding=true，标准错误为空。已留窗口供用户继续使用。
6. 新 ZIP 的 17 个文件逐项 SHA256 与正式发布目录一致。

## 使用与边界

入口仍为 `artifacts/portable/current/Desktop.App.exe`。新压缩包为 `artifacts/publish/ChaoxingStudyDesktop-portable-startup-fix-win-x64.zip`；之前的 ui-env ZIP 属于本次修复前版本。

解压完整文件夹并双击 EXE，确认窗口正常打开并自动访问学习通。根目录的 6 个 DLL 为启动必需文件，不能只复制 EXE。仍需 WebView2 Runtime，以及可写的应用用户资料目录。真实平台交互验收范围与前一版一致。
