# 自动提交与登录保持

日期：2026-10-21。

## 自动提交

用户已要求填写后自动提交。程序对当前文档全部识别题目读回核验，通过后才点击明确的提交按钮，并处理本次提交的原生确认或页面内确认。漏答、不支持题型、题目变化、网页提示未答/未完成时停止提交确认；同一组题不重复提交。停止按钮取消后续操作。达到识别上限（100 题）的页面不自动提交。

本机验收计数新增 `SubmissionsRequested`，仅代表已点击提交，不能据此认定服务器接收成功或答案正确。分页试卷和未知确认布局仍需实际页面验证。

## 登录保持

发现此前不同发布包使用各自 `data/BrowserProfile`，导致升级版本时换了登录资料。现在优先复用固定资料；系统用户目录不可写时，项目内各版本统一使用 `artifacts/client-data/`。首次从最近使用的旧发布包复制资料，原资料保留；迁移失败提示关闭旧版重试，不用空资料静默替代。

关闭窗口时，在浏览器销毁前保存超星/学习通会话 Cookie；仅使用 CookieManager API，持久 Cookie 与网站存储仍由 WebView2 profile 管理。会话恢复文件 `session-cookies.bin` 使用 Windows DPAPI CurrentUser 加密，最长 7 天，不改写网站到期时间或绕过服务器会话校验，不保存其他站点的会话 Cookie。清除登录同时删除恢复文件，避免重新恢复已清除登录。

平台会话过期、撤销或要求再次验证时仍需正常登录。本次升级后的首次登录状态能否直接沿用，须以迁移后平台反馈为准。

- 两进程验证：持久 Cookie、网站存储、会话 Cookie（含 Secure/HttpOnly/IsSession）恢复，以及清除登录后恢复文件消失。

## 真实复测

1. 关闭旧客户端，打开 `artifacts/publish/auto-submit-login/Desktop.App.exe`，核对原登录是否可用；需要时正常登录一次。
2. 进入可测试的练习，确认填写后提交成功，并核对网页反馈。
3. 正常关闭新版，再打开同一新版，核对是否无需重新登录。

上述真实自动提交和重启免登录仍待复测，离线通过不能替代平台反馈。
