## 实现

- 首页和首页按钮：`https://i.chaoxing.com`。
- 原生注册跨域和嵌套框架，逐帧读取与操作；导航代次、文档 ID 和题目内容指纹阻止旧答案写入。
- 正常 HTML 媒体自动播放与同课时连续播放；手动暂停后不反复恢复。自动播放受浏览器限制时提示手动点击。
- 按章节目录完成标记推进；点击去重，12 秒无切换暂停。单纯 `ended` 不代表平台完成。
- 右侧课程类型、章节完成率、当前课时视频播放比例；每 2 秒读取。完整章节目录标记完成后同课程每进程重新加载一次。
- 根目录 `.env` 读取，保留现有密钥，按用户指定配置 `glm-4-flash`；HTTPS 请求在原生端发出，不向网页传递密钥，不跟随重定向。
- AI 单选/多选/判断/多空严格 JSON 校验、预览、确认填写和读回。HTTP 401 不重试，429/5xx 最多重试两次，整体 60 秒超时，可取消。

## 人工验收步骤与限制

1. 在已打开的客户端正常登录，选择一门可测试的课程。
2. 核对右侧课程类型与网页目录完成数，点击开始自动播放，观察视频播放位置变化；点击停止应暂停且不继续推进。
3. 当前章节真实完成后，确认仅进入下一节一次；加载失败应暂停并提示。课程全部完成后核对一次自动重载后的统计。
4. 打开可测试题目，生成 AI 答案，检查预览后确认填写；核对所有字段，再由用户在网页确认提交。检查提交后的平台状态。
5. 退出重开核对登录资料；异常记录错误提示与页面布局，勿分享密码、Cookie 或密钥。

总体百分比是目录章节完成率，尚不支持任意平台任务点加权统计或分页目录补全；视频比例是当前课时播放比例。已实现单一混淆字体的字形映射，未识别字体或不完整映射仍停止生成；图片题、非标准题型、文档翻页和自动交卷不在本次实现中。真实页面选择器覆盖率、服务端进度更新延迟、全课程流程稳定性仍须以账号验收为准。
