第一条　定义与产品说明

1.1 本软件：指由我们提供的 Windows 桌面客户端（当前版本 0.3.0，基于 C# / .NET 10 / WPF / WebView2，支持 Windows 10/11 x64），以及其随附的页面资源、字体映射表、许可证文件和更新版本。

1.2 第三方平台：指本软件所访问的学习通、超星等在线学习网站及其运营方。本软件并非第三方平台的官方产品，未获得其授权、赞助或背书，与第三方平台不存在隶属、合作或代理关系。

1.3 为便于您准确理解，本软件的实际功能与行为如实说明如下：
（1）在桌面窗口内嵌浏览器中打开第三方平台网站，由您本人自行登录，本软件不提供账号、不代为注册或登录；
（2）支持多账号配置与隔离（同时常驻实例有上限），会话 Cookie 采用 Windows DPAPI 加密本地保存，按当前 Windows 用户恢复，会话最长保留约 7 天；平台自身会话过期或撤销后仍需您重新登录；
（3）支持视频、音频自动播放、倍速调节、播放进度阈值判断及章节完成标记读取，您可自行开启"章节完成后自动进入下一节"；播放期间对鼠标离开、窗口失焦、页面可见性变化等事件进行拦截以防止暂停，停止后解除；
（4）支持文档类任务点的自动翻页与滚动浏览；
（5）支持题目识别（含字体解析与本地 OCR）与 AI 辅助答题：由您自备大模型 API Key，本软件调用您所配置的第三方大模型接口生成参考答案，读回核验后填写，并在满足条件时点击提交及确认；
（6）提供"按课程执行自动流程"、最近运行日志、恢复上次课程等辅助功能；
（7）本软件在本地运行，配置、Cookie、缓存与密钥均保存在本机；AI 答题需联网访问您所配置的第三方服务。

1.4 本软件显示的章节进度、视频播放比例等为本软件依据页面可见信息计算的结果，并非第三方平台的官方成绩或完成记录；"平台是否已记录学习、是否已接收答案"以第三方平台的页面反馈为准。
